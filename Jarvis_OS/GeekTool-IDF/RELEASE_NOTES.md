# v1.9.3 · 小咪、行情与自动演示正式版

在v1.8基础上加入完整小咪离线宠物、自选股票行情和拍摄演示模式。正常启动器共26项，原24项编号、62款表盘和已保存选择保持；正式与内测OTA通道同时更新为v1.9.3。地图仍为浏览器原型，不是固件功能。

## 更新内容

- 小咪全屏离线宠物：25套眼睛表情、14段身体动作，含完整Play/Orbit/Comet彩环和淡入淡出；支持轻点、滑动、张望、眨眼、困倦唤醒和长按返回。复用既有只读资源卷，后台双缓冲准备，保留完整矢量回退；不提供AI对话或联网宠物服务。
- 自选行情：最多8只沪深港美代码，默认多只报价总览，三行可见并滚动；逐只发布价格、涨跌、来源币种/时间，失败独立标记旧行情。整份自选包括屏外行刷新，支持添加、移出和NVS保存。腾讯公开行情可能延迟，不承诺交易所实时性或长期服务契约。
- 拍摄演示：设置中进入，自动巡演原24个应用、62款表盘及子功能共138场景，支持暂停、手动前后切换和退出。演示使用隔离样例，不发起真实网络、录音、HID或OTA操作，不修改原设置/计数；股票和小咪未加入演示目录。
- 启动器、双语字体、图标与各App演示适配一并整合，保留原音频、蓝牙、锁屏、录音和导航契约。

## 小咪素材与升级边界

- 普通应用OTA只更新应用，不迁移/格式化分区，也不会写入小咪素材或初始化录音卷。需要已有双8MiB应用槽；旧3MiB/4MiB布局不能直接升级本包。
- 加速需要资源卷已有`/img/MIMI.PAK`。Release附带已验证的原始span包和许可/安装边界说明；包为6,361,744字节，SHA256 `fea8e0c7140c946b414bdf2ad59079b7de2f3deef10c5c2b8934fa7aea21d42c`。此文件不是应用固件，不能通过应用OTA按钮写入。
- 没有包时全部表情、身体动作和彩环仍保留，使用较慢的原矢量路径。不得为安装素材覆盖用户完整资源卷；开发者需按当前设备备份和变更扇区方案安装，见附件`MIMI-ASSETS.md`与源码[MIMI.md](https://github.com/soBigRice/soRound_os/blob/v1.9.3/GeekTool-IDF/MIMI.md)。
- 前序已安装本地候选的三段彩环约12～16fps，未全部达到17fps；未采用最后失败的canonical素材。该数字不等于本次精确CI镜像或所有设备的帧率。
