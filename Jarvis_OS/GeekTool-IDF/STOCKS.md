# 自定义股票行情

核对日期：2026-11-04。A版股票已按用户“全部新代码一起烧录”的授权随整合固件安装，本台启动和数据保护检查通过；现已随v1.9.3正式发布，真实行情网络、触摸和视觉仍待验收。用户选择A“弧边清单”不等于实现或设备验收；精确镜像与范围见[整合安装回执](PORTING_NOTES.md#2026-11-03-整合本地新代码设备安装)。

## 页面与已确认约束

- 启动器末尾“股票 / Stocks”默认进入自选行情总览。每行同时显示名称、价格、带市场前缀的代码、来源币种、涨跌幅、来源日期/时间和获取状态。一屏显示三只，滚动查看其余；每轮覆盖完整自选列表，包括屏外项目。点击一行进入该只详情，返回仍是行情列表。
- 最多8只，沿用原独立自选记录；支持添加、确认移出和重启读取。输入页先选择沪/深/港/美，再输入数字代码或美股字母ticker，数字市场使用数字键盘。沪深6位、港股5位、美股1～10字母；不支持裸数字推断市场、北京市场或带点/连字符的美股类别代码。
- 空列表提供添加入口；读取失败只允许重试，不写空记录。重复、超量或不合法代码不保存。新增成功后回到全自选总览，移出一只后其余股票缓存按身份顺序保留。
- 一轮进行中逐只发布结果，先成功的先显示，不能等最慢的一只才显示全部。单只失败不清空其他股票，也不覆盖该只上次成功报价；对应行明确标记旧行情，并保留真实行情时间。首次失败显示未获取，不用样例报价兜底。
- 页面可见且处于总览/详情时自动刷新整份自选；每轮完成后间隔15秒发起下一轮。真实周期还包括请求时间，不能承诺所有价格严格每15秒变化。点击底部“刷新”或顶部刷新图标立即查询全部自选，进行中禁用重复请求。编辑、确认移出、锁屏/遮挡及退出停止新查询，返回/恢复可见重新查询。
- 切换总览/详情只是切换视图，不取消整轮请求，不把刷新范围缩回选中单只。沪深/港股涨红跌绿，美股涨绿跌红，正负号同时保留。币种来自来源字段，例如 `hk80700` 是CNY柜台，不能按港股前缀误标HKD。
- 行情源可能延迟，闭市可以显示上一交易日来源时间；不把本机时间、请求完成时间或“已获取”标记当作交易所实时性证明。详情保留完整来源时间及市场时间提示。
- 原24项应用、编号、设置、分区及拍摄演示模式保持；股票尚未加入原演示适配器。

## 数据源与调度选择

继续使用[腾讯UTF-8 JSON入口](https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600519)，只解析 `data[code].qt[code]` 的报价，不从分时点推算现价。复用证书包、ESP-IDF6.0.1、PSRAM分配、`network_http_get`和cJSON，不新增网络依赖或代理服务。

2026-11-03最小实验：给该UTF-8入口传逗号分隔代码，实际返回 `code=-1 / code param error`；另测可多代码的 `qt.gtimg.cn?fmt=json&utf8=1` 仍不是UTF-8。没有用“一个请求成功”宣称多代码已经支持，也不为本轮引入一套GBK转换或并发TLS连接。当前选择是一个worker顺序请求整份自选，复用一份32KiB正文，并逐只发布，避免多TLS连接挤占内部堆。

公开入口可匿名访问，但未找到公开版本化契约或长期服务承诺，不据此推断商业再分发授权。此前核对的[AllTick免费版](https://alltick.co/zh-CN/pricing)限制演示品种，[Twelve Data沪深目录](https://twelvedata.com/exchanges?level=overview)为EOD，不能直接替代本轮任意自选。未购买套餐或申请密钥；如要求有保证的交易所实时行情，需另行确认数据源和费用。

## 真实调用链

`launcher.c::APPS[24] → app_stocks.enter → stock_list_load → build_list → begin_request`。

`stocks_fetch_begin(&list, token) → fetch → 遍历完整list → network_http_get → stock_quote_parse → publish → stocks_fetch_poll → tick → render_row/render_quote`。

- `stocks_fetch.c`持有一份 `stock_batch_t`：不可变代码列表、逐项结果/状态、revision和complete。每完成一只递增revision；UI只在revision变化时合并并绘制，先核对整份列表及每个位置的代码，防旧列表错位。
- 单个worker、最多两次共享传输尝试、单只6秒I/O/8秒预算；整轮共用24秒预算，后续请求只使用剩余预算。耗尽或掉线时，未处理项目显式失败/离线，已经成功的保留。SDK阻塞DNS等可能超过预算检查点，这不是硬墙钟终止保证。
- `pause_refresh`用于编辑/移出确认/遮挡/退出，作废generation，不在SDK I/O中强杀任务。旧worker仍清理时UI等待BUSY最多10秒，正式开始后重新计时，整轮UI等待30秒；迟到或取消结果不能写入新列表。
- `clear_view`只销毁LVGL视图，不能顺便取消整轮。总览/详情导航共用同一批行情；新增/移出会先取消原轮，保存成功后按新列表重新请求。
- UI的全量poll快照使用静态存储，不向LVGL线程栈塞入8份报价。worker复用一个PSRAM优先的正文缓冲，一轮结束释放；退出清理页面指针，隐藏页不继续网络刷新。
- 沿用 `stock_quote_parse` 对业务码、市场/代码、UTF-8、有限十进制、涨跌方向、来源币种及真实日期的验证。缓存只接收当前代码的合法成功结果。

## A版圆屏布局与触控

`build_list → render_row → layout_rows`：466×466画布，标题位于顶部56px，摘要92px；列表从122px开始，三个89px高的透明行。`layout_rows`根据每行当前滚动位置和圆弦重新安排左右边界，中间行较宽、首尾行内收，保持名称、完整报价、来源时间和涨跌胶囊。页码说明当前可见范围，超长报价减小字号，仍过长时循环展示，不截去价格精度。

`arc_button → arc_control_event`使用LVGL原生圆弧/线段画底部双环扇区，外半径207px、内半径175px；`LV_EVENT_HIT_TEST`按同一圆心、半径和角度命中，并扩展8px触控余量。矩形包围盒边角和按钮中间空隙不响应。列表行命中也限定在圆内；`row_event`只在绘制或命中事件读取页面坐标，退出后的DELETE事件不能访问已清空的root。

`launcher.c::header_app_style`仅为股票设置450px直径、3px宽电量环与透明44px返回键，保持原电量颜色/充电含义；返回主屏恢复458px、8px环，其他应用仍使用各自样式。主机检查覆盖真实启动器切入/返回，读取坐标前先完成LVGL延迟布局。

## 保存、字体与地图入口

`stocks_store.c`沿用NVS namespace `stocks`、key `watchlist`、130字节版本1记录：版本、数量、8个16字节代码。不保存报价、不改原格式或分区；保存失败不推进当前列表；未知版本/损坏内容/读取失败不自动覆盖。Flash故障/掉电原子性仍不能用主机fake证明。

`app_stocks.c`负责视图、状态合并和交互；`stocks_fetch.c/h`负责整轮请求；`stocks_data.c`负责代码和来源解析。图标仍由 `companion_icons.c::stocks_icon`绘制。

股票静态12/14/16/17/18/20/22/24/31px字体由 `tools/gen_stocks_fonts.swift`生成，31px价格使用本地Helvetica Neue Medium。列表动态简称使用 `font_stocks_cjk_22`，详情保留 `font_stocks_cjk_20`；二者复用现有MIT `lv_font_conv 1.5.3`与本地PingFang的GB2312一级3755字、2bpp RLE生成方式，保持原32px答案字库。超出当前字库的简称显示准确代码，不显示方块。22px字库由 `tools/gen_answer_cjk.py --size 22 --font-name font_stocks_cjk_22 --output main/font_stocks_cjk_22.c`生成；20px对应 `--size 20 --font-name font_stocks_cjk_20 --output main/font_stocks_cjk.c`。工具默认32px/原字体名不变，另需原有 `--font-collection/--converter`参数。

## 用户纠正与防复发

2026-11-03：用户否定初版UI，补充要求展示全部自选行情，并明确选择“行情列表，多只同时看”。此前列表只有代码和删除入口，worker只请求selected，不能作为全自选行情总览交付。当前将默认首页、每行价格/涨跌/时间、完整列表刷新、屏外数据更新和独立失败状态同时落实。

后续修改优先检查：
1. 默认页面是否直接看到多只报价，而非进入逐只详情或代码管理页。
2. 请求输入是否是完整自选，不受选中项或可见窗口限制。
3. 截图用多只、不同市场和失败项目，不能用空列表/一只股票证明总览完成。
4. 单项失败、切详情、增加/移出及遮挡后，其他行数据身份和刷新范围是否保持。
5. 中文字体必须和行高匹配，不能把32px动态字库塞进紧凑20px行。
6. 圆屏先核对设计图的圆弦空间与原生绘制，不能仅把矩形卡片裁圆；触控范围同时检查弧带、边角和中间空隙。销毁事件可能发生在App退出清空指针之后，事件回调先判断事件类型与生命周期，再读取页面坐标。
