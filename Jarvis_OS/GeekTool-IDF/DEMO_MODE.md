# 拍摄演示模式

核对日期：2026-11-04。现已随v1.9.3正式发布；下文2026-10-22的烧录属于历史候选，精确CI镜像本次未写设备，真实圆屏观感与连续长时间播放仍待用户验收。

## 使用

设置首页向下滚动，点击「演示模式 / Demo mode」。自动循环展示24个应用、62款表盘及主要子功能，共138个场景。第一段先展示每个应用一次，随后展开其余表盘和子页面；普通场景停留6.5秒，表盘停留3.5秒。

- PWR短按：暂停 / 继续。暂停保留当前画面，手动切换后仍暂停。
- 点击屏幕或底部`DEMO`进度：打开控制面板，选择上一项、暂停 / 继续、下一项、退出。面板3秒后收起。
- 左右滑动：下一项 / 上一项；首尾循环。
- BOOT短按、普通场景的顶部返回键，或控制面板的关闭按钮：退出到启动器。BOOT长按仍按原规则关机。

演示期间保持亮屏，遮挡 / 恢复不补算后台动画时间。退出后恢复正常锁屏、电量环和导航。演示不自动随开机启动、不保存进度，也不写入新的设置键。

## 内容与数据边界

| 内容 | 展示范围 |
| --- | --- |
| 表盘 | 62款原生全屏绘制；不切换用户保存的表盘ID。照片样式读取设备已有只读图片资源 |
| 设置 / 系统 / Wi-Fi | 设置首页及七项详情、系统三页、无线列表与密码键盘 |
| 天气 / 日历 / 计时 | 天气首页与四段详情、日历、倒计时设置与运行、秒表记圈 |
| 互动工具 | 动态频谱、水平仪、十二张真实迷宫路线、粒子流体、三套方块配色、三种骰子数量与硬币 |
| 蓝牙 | 鼠标、演示翻页、音乐、音量；数字孪生姿态样例 |
| 生活应用 | 答案翻页、十二星座及五类内容 / 选择页、木鱼动画、生态箱昼夜、专注三种音景界面、录音 / 播放 / 列表样例 |

`DEMO`标记始终显示。天气、网络、姿态、频谱、运势、录音、媒体封面 / 文字与OTA进度是独立显示样例；音乐样例文字不代表正在播放的歌曲。系统信息、版本、设备设置和日历沿用只读信息。音景、录音回放与木鱼在演示中仅展示界面 / 动画，不启动声音硬件。

演示适配器不发起HTTP、扫描、配对、HID输入、OTA、录音文件操作或计数保存，也不修改真实天气缓存、Wi-Fi凭据、生态箱成长、专注偏好或功德计数。系统原有后台服务继续按原规则工作；这不是飞行模式。未配置录音区时也可展示样例，不进行分区初始化。

## 调用与生命周期

`app_settings.c::open_page(SETTINGS_DEMO)` → `launcher_start_demo()` → LVGL异步回调 `demo_start_deferred()` → 正常退出设置 → 隐藏入口 `app_demo.enter()`。演示仍覆盖原24项；当前正常启动器另有股票和小咪，未加入演示适配器。旧应用索引和设置格式不变。异步启动会检查当前仍处于未锁屏的设置页，避免退出后的过期请求再次打开演示。

`demo_mode.c::chapters`按应用绑定各`app_*.c`导出的`demo_page_t`。适配器复用正常页面的控件构建 / 绘制函数，独立`frame(elapsed_ms)`只更新演示画面；正常入口继续调用原服务和保存逻辑。场景数从适配器和`watchface_count()`派生。

`app_demo.tick()`由原启动器33ms节拍调度：处理PWR → 处理退出 / 手动切换 → 推进未暂停的演示时钟 → 到时切换 → 更新当前画面。当前场景退出后同步删除页面，再创建下一页；只有流体沿用自身定时器，其可见性回调负责暂停 / 恢复，退出停止定时器并由对象删除释放画布。方块暂停时也通过原可见性回调释放CPU频率锁。木鱼和音乐沿用原图像缓存 / PSRAM释放路径。

透明输入层位于所有场景对象之上，拍摄点击不能进入真实控件；控制面板位于输入层之上。Wi-Fi演示密码框构建在场景容器内，不能使用正常密码框的系统顶层；全屏表盘 / 密码页通过`launcher_demo_chrome()`暂时收起共享表头。演示密码框同步销毁，避免其父页面删除后仍存在异步删除请求。快捷面板下拉在演示中不打开；退出后恢复。
