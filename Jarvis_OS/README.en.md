# Jarvis_OS

Jarvis_OS brings the complete soRound_os firmware to the Waveshare ESP32-S3-Touch-AMOLED-1.75C and adds a native Codex companion plus a Grok Bot expression clock. The upstream launcher, settings, watch faces, utilities, audio features, games, and recorder remain available.

The Codex app has read-only Usage, Radar, Activity, and VibeBuddy pages. It discovers the Mac bridge on the local network and keeps the last valid snapshot when the bridge is offline. The expression clock shows time, date, and battery, and changes expression after a full-sleep wake.

See the [main project guide](../README.md) for build, flash, testing, partition, and bridge instructions. The imported upstream guide is preserved in [`UPSTREAM_README.en.md`](UPSTREAM_README.en.md).
