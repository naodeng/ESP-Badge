## 直接使用

- `发布配图/`：01–16，全部 1080×1440、3:4；JPG 可直接发，PNG 为无损备份。同一编号只选一种格式上传。
- `发布文案.md`：可直接复制的标题、正文和话题。
- `00-配图总览.jpg`：快速看全部排版；不是单张发布图。
- `index.html`：本地总览，点击图片查看大图。
- `备选配图/`：17 地图视觉概念。该页不计入明日正式版功能承诺，默认不和 01–16 一起发布。
- `素材原图/`：原始 PNG/SVG、正常/AOD、双语、交互状态与设计留档。素材复制后保留原像素；`素材清单.json`可追溯来源和摘要。
- `排版源文件/`：每页 HTML、共享 CSS 与排版生成脚本；素材在本地，不依赖在线字体。

推荐上传顺序：封面 → 七组新表盘 → 表盘入口与图标 → 方块 → 生态箱 → 专注 → 遥控台 → 声音胶囊 → 迷宫/粒子/木鱼 → 体验与官网。即文件编号 01→16。

## 内容边界

- 正式版发布日期是用户本轮明确指定的发布安排。制作宣传素材不等于已经执行固件发版、官网部署或设备刷写。
- 主图使用实际 LVGL 控制器或绘制器导出的 UI；电量、时间、专注、录音等为固定样例，不冒充设备照片或现场运行数据。
- 运动图形表达时、分、秒；不宣传心率、计步、热量、GPS、导航或月相能力。
- 遥控台主图只展示鼠标、演示和媒体控制。封面/文字回传仍有实际 ATT 失败记录，歌词仅支持显式绑定本地 LRC；带合成歌词的原图仅在素材留档内。
- 声音胶囊保留独立存储初始化条件；没有将普通固件升级写成自动完成录音卷迁移。
- 历史染料、被拒绝的银色款、旧 STUDIO 背景、B/C 图标方向等只作设计留档，不列入当前功能。
- 地图三稿为 AI 视觉概念，地理细节非真实服务结果；主发布序列不包含定位/导航承诺。
- 文案只描述具体优化，不写未经测量的 FPS、功耗、提升百分比或「全部无卡顿」。

本轮在 Tabbit 真实浏览器中逐页加载 17 页，1080×1440 检查图片加载、页面边界和内容与页脚间距；第一轮发现多状态页面挤占页脚，已按实际尺寸收紧图组，第二轮全部通过。已查看封面、几何读时原生主图与最终全图总览；成图、JPG 副本及原图摘要另作文件验证，摘要见 `验证回执.json`。

排版源码只在此目录写入，未改固件和官网源码，未暂存、提交、推送或发布。生成页面：

```sh
python3 -B 排版源文件/build_pack.py
```

浏览器以 1080×1440、device scale 1 打开每个 HTML，等待 `document.fonts.ready` 和图片加载，再截取 `main.poster`。JPG 是 PNG 的 RGB 转换，quality=95、subsampling=0；所有源截图保留。结束后关闭本轮本地 HTTP 服务与浏览器临时页；不清理其他任务的页面和构建。
