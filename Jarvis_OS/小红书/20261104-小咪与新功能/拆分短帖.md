# 拆分稿一：小咪

标题：我把离线小宠物装进了ESP32圆屏

配图：主套图01→02→03→04→08。01作为封面，08说明开发状态与项目出处。

最近给 soRound OS 加了一只小宠物，叫「小咪」。

一个白团子，两只黑眼睛，不用联网，也不用登录。

点一下换眼睛表情，划一下触发身体动作。它会眨眼、张望、变形，还会绕起彩色圆环。放着不碰，过一阵会犯困、睡着，碰一下又醒过来。

现在接入了25套眼睛表情和14段身体动作。全屏只留这个小家伙，想退出时长按，叫出返回按钮。

形象和动作基于 GrokBot / bloub 开源项目适配，圆屏交互继续慢慢打磨。

目前是本地开发版，尚未公开发布；配图为原生界面预览，动作观感与流畅度还在调试。

已有正式版与项目说明：GitHub · soBigRice/soRound_os

# 拆分稿二：自选行情

标题：我给ESP32小圆屏加了自选行情

配图：主套图05→06→08。05作为封面。

想让桌上的小圆屏，除了看时间，还能顺手看一眼自选股票。

于是给 soRound OS 加了一个自选行情页。

支持沪深、港股和美股，最多添加8只。首页一屏看三只，滚动看其余，点一行进入单只详情。名称、代码、价格、涨跌幅、币种和来源时间，都放在同一页。

这次也把一些不太显眼的细节补上了：

• 自动查询整份自选，屏幕外的股票也会更新。
• 单只查询失败单独标记，保留上次报价和时间。
• 沪深、港股涨红跌绿，美股涨绿跌红，同时保留正负号。
• 添加或移出后保存自选列表。

行情源可能延迟；配图使用固定样例，不代表正在展示实时行情。

目前还是本地开发版，尚未公开发布，网络和触摸体验继续验证。

已有正式版与项目说明：GitHub · soBigRice/soRound_os
