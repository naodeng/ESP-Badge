# Jarvis 出行速度表

当前版本包含 ESP32-S3 固件接收服务、圆屏速度／航向页面，以及浏览器数据发送器。发送器能在支持 Web Bluetooth 的浏览器中选择 `JarvisTravel`，请求系统配对并用加密 GATT 写入发送 20 字节帧。定位由手机浏览器提供；模拟模式会设置 DEMO 标记。

## 试用

1. 在一个安全 HTTPS 页面（或本机 `localhost`）打开 `index.html`。Android Chrome 等支持 Web Bluetooth 的浏览器可尝试；iOS Safari 不支持本页用到的 Web Bluetooth API。
2. 在出行应用前台时点击“连接 Jarvis”，选取设备并完成配对。服务 UUID `7f3a9001-2c91-4f8a-9d2e-51c034cd1300`，写特征 UUID `7f3a9002-2c91-4f8a-9d2e-51c034cd1300`。
3. 点击“使用手机定位”并允许定位权限，或启动模拟数据。模拟显示红色并标注“模拟数据”。停止定位后，设备在 5 秒内清除旧读数。
4. 屏幕仅显示速度、运动航向和定位精度。低于 1.5 m/s 时不显示航向。当前没有路线规划或地图。

## BLE 帧 v1（20 字节，小端）

| 偏移 | 字段 | 单位／规则 |
|---:|---|---|
| 0 | 版本 | 必须为 `1` |
| 1 | 有效位 | bit0 速度，bit1 航向，bit2 精度，bit4 模拟；其余位必须为 0 |
| 2–3 | 序号 | uint16；允许正常回绕，拒绝重复和倒序 |
| 4–7 | 会话 ID | uint32，非零；连接期间不可改变 |
| 8–9 | 速度 | cm/s，最大 10000；缺失填 `0xFFFF` |
| 10–11 | 航向 | 0.01°，范围 `[0,36000)`；缺失填 `0xFFFF` |
| 12–13 | 精度 | 0.1 m；缺失填 `0xFFFF` |
| 14–15 | 样本年龄 | ms，最多 5000 |
| 16–19 | 保留 | 必须为 0 |

每帧均重新校验。无效帧不会覆盖快照或刷新过期计时。接收间隔与帧中样本年龄合计超过 5 秒即隐藏读数。BLE 栈仅在应用前台活动；离开页面、被遮挡或断开连接都会清空数据。

## 尚待验证

- ESP-IDF 编译、主机协议测试和 LVGL 页面回归。
- Android/iPhone 真机定位与 BLE 行为；本轮发送器不兼容 iOS Safari。
- BLE 配对安全、连接复原、锁屏和遮挡后的行为。
- 不含地图与导航指令；QMI8658 暂未用于航向融合。不能把此工具作为骑行安全导航设备。
