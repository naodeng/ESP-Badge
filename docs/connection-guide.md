# MOTO GPS 手机 App 与 Jarvis_OS 圆屏连接指南

本指南介绍 iPhone MOTO GPS App 与 Jarvis_OS 圆屏之间的 BLE 连接、首次配对、导航同步和排障。网关负责手机上的搜索和路线；BLE 负责手机与圆屏之间的近距离数据同步，是两条独立链路。

## 1. 连接前检查

- 圆屏使用适配 Moto GPS 的 `Jarvis_OS` 固件，并已正常开机。
- iPhone 已安装 MOTO GPS App，蓝牙已开启。
- 两台设备靠近，首次配对时让 iPhone 保持解锁。
- 为了让 App 展示真实地点和路线，网关也需正常；但网关故障不会阻止 BLE 配对。

## 2. 首次连接步骤

1. 在圆屏启动器中打开 **MOTO GPS** 页面并停留在页面上。设备侧 BLE 服务是在进入该页面时启动的；刚开机但还没打开此页面时，手机无法找到圆屏。
2. 在 iPhone 打开 MOTO GPS App。首次使用时允许 App 使用蓝牙。
3. 在首页右上角点圆屏图标打开 **我的圆屏**；也可以在首页设备卡片打开。
4. 点 **连接圆屏**。页面应先显示“正在寻找圆屏”，发现后显示“正在连接”。
5. 首次加密连接时留意 iOS 的蓝牙配对提示；出现提示后按系统要求接受。偶尔第一次物理连接会断开并自动重试，保持页面打开并等待再次连接完成。
6. 页面状态显示 **已连接** 后，圆屏已完成 BLE v1 握手和加密，可接收导航数据。

如果 App 已自动开始搜索，无需重复点连接；如状态为“连接未成功”，点 **重新连接**。

## 3. 开始导航并检查同步

1. 先在 App 的[网关设置](mobile-app/configuration.md)确认根地址和健康检查。
2. 在首页搜索目的地，选择地点并选择一条路线。
3. 在安全、静止状态下开始导航，确认 iPhone 定位权限可用。
4. 圆屏收到连接状态、路线和当前转向后会更新导航页面；后续的导航状态由 App 自动同步。
5. 先在停车状态验证路线、转向、剩余距离和进度，再测试行驶中的定位更新。

不要在骑行中操作手机。应在出发前完成搜索、路线选择和连接检查。

## 4. 屏保解锁与页面返回

- 短按设备 **BOOT** 键可锁定或解锁屏幕。在屏保表盘下半部向上滑动约 80 像素，也可回到锁屏前的桌面或 App；普通轻触和短距离滑动不会解锁。
- 上滑只在屏保页面生效，并要求从屏幕下半部开始、向上移动至少约 80 像素。手势不够长时，屏保保持显示；仍可短按 BOOT 解锁。
- 打开 App 后，长按侧边 **PWR** 键返回。若当前 App 有子页面，会先退回上一级；否则回到启动器。MOTO GPS 页面左右滑动仍用于切换导航、速度、罗盘和音乐页面。
- **BOOT 长按约 2 秒**仍为关机操作。请勿与 PWR 返回混淆。

## 5. 状态含义

| App 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 蓝牙不可用 | iPhone 蓝牙关闭、权限关闭或系统蓝牙不可用 | 开启蓝牙，并在 iOS 设置中允许 MOTO GPS 使用蓝牙 |
| 正在寻找圆屏 | App 正在扫描 MOTO GPS 服务 | 确认圆屏开机并停留在 MOTO GPS 页面，手机靠近后等待片刻 |
| 正在连接 | 已发现设备，正在建立 BLE 连接、加密和协议握手 | 首次连接时保持解锁，接受系统配对提示并继续等待 |
| 正在准备 | BLE 已连上，协议握手尚未完成 | 不要立刻断开；若持续不变，重新打开页面并重连 |
| 已连接 | BLE 加密和导航协议握手完成 | 可开始导航；路线仍需由手机网关成功获取 |
| 连接未成功 | 扫描、连接、服务发现或握手未完成 | 核对设备页面、手机权限和固件版本，然后点“重新连接” |

## 6. 常见问题排查

### 一直显示“正在寻找圆屏”

1. 看圆屏当前页面是否真的是 **MOTO GPS**，不要停留在表盘或启动器。
2. 回到启动器后重新打开 MOTO GPS 页面，然后在 iPhone 点“重新连接”。
3. 检查 iPhone 的 **设置 → 隐私与安全性 → 蓝牙**，确认 MOTO GPS 已获准访问蓝牙；也确认系统蓝牙已打开。
4. 将 iPhone 放到圆屏附近，暂时关闭另一个手机或旧 App 对该圆屏的连接。
5. 若仍找不到，确认设备刷入含 BLE 广播修复的 Jarvis_OS 固件。调试时串口应看到 `advertising started; name=Jarvis_OS`。

### 找到设备但配对/连接失败

- 首次连接时保持 iPhone 解锁，留意 iOS 配对提示；系统提示弹出后按提示接受。
- 等待 App 自动重试一次，不要在首次连接瞬间反复开关蓝牙。
- 若先前曾在系统蓝牙设置中手动移除设备，重新打开圆屏 MOTO GPS 页面后从 App 连接。
- 若仍持续失败，记录 App 连接状态和设备串口中的 `iPhone connected`、`link encryption ready` 或断开原因。不要为了绕过配对问题擦除设备 NVS 或用户数据；协议要求 BLE 加密。

### App 显示“已连接”，圆屏没有路线

- “已连接”说明 BLE 连接和协议握手完成，不代表手机已经获取路线。
- 在 App 检查网关测试、地点搜索、路线选择和定位权限。
- 如网关健康检查通过但搜索或路线失败，按[后端部署指南](backend/deployment.md)检查 AMap Key 和 Worker 日志。
- 确认导航已在 iPhone 开始；连接恢复后 App 会同步当前导航状态。

### App 显示“连接失败”但网关测试正常

这是 BLE 与 HTTPS 网关两个独立链路。回到圆屏打开 MOTO GPS 页面，确认 iPhone 蓝牙权限，然后在“我的圆屏”中点“重新连接”。

### 圆屏顶部文字重叠

最新固件已移除 App 页面上的全局返回箭头，返回通过 PWR 长按完成；这样 App 自己的标题不会再被箭头遮住。若 MOTO GPS 顶部仍重叠，确认已安装包含本轮 UI 修复的固件，再按[固件部署指南](deployment/README.md)重新刷写。

### 屏保怎么回到桌面

从屏幕下半部向上滑动至少约 80 像素；轻触或短距离滑动不会解锁。如果上滑没有生效，短按 BOOT 键即可解锁。解锁后会回到进入屏保前的桌面或 App。

## 7. iPhone 定位与后台权限

- **定位“使用 App 期间”**：用于按当前位置搜索地点及规划路线。
- **定位“始终/允许后台”**：用于导航时锁屏或切换 App 后继续更新位置。
- **蓝牙**：用于扫描、连接圆屏和发送导航状态。
- **Apple Music**：只影响圆屏音乐信息和媒体控制，不影响 BLE 导航。

可在 iPhone **设置 → MOTO GPS** 中调整权限。若系统没有再次弹窗，检查该页当前权限状态。
