# Jarvis_OS × soRound OS UI 适配方案

## 目标

以 soRound OS 的 ESP-IDF 固件为完整功能底座，保留它现有应用、表盘、设置、录音、连接和电源行为；加入本项目的随机表情时钟屏保与 Codex 功能。新增页面应像 soRound OS 原生页面，不把旧固件的桌面、卡片或配色直接搬过来。

项目固件目录最终使用 `Jarvis_OS/`，README、构建入口、工程显示名称和目录示例同步更新。旧目录 `agent-badge/` 中只迁入确认要保留的 Codex 桥接/数据功能、表情时钟素材与实现；原先删除的应用以 soRound OS 主线为准全部保留。

分项设计见 [Codex 原生 UI 适配](2026-11-12-codex-native-ui.md) 与 [表情时钟表盘](2026-11-12-expression-watchface.md)。

## 视觉与交互原则

- 使用 466×466 圆屏安全区；重要文字、触控目标和圆弧不得贴近屏幕裁切区。
- 使用 soRound OS 的黑色背景、暖白主文字、灰色次级文字和单一红色强调。电量充电等系统语义色仍遵从上游规范。
- 遵循“单页聚焦一个任务”的原生应用框架：原生标题/返回、克制的局部切换动画、紧凑状态信息；避免旧版多色渐变、悬浮卡片和重复导航。
- 复用现有启动器、应用生命周期、锁屏表盘、AOD/睡眠与设置流程。Codex 的轮播只发生在 Codex 应用内部，不增加新的桌面层级。

## 表情时钟屏保

- 将表情时钟接入 soRound OS 的 watchface 目录，作为新增表盘供设置中的现有表盘选择器管理；不另造一个覆盖层或第二套锁屏。
- 把新表盘追加到目录末尾，保留上游已保存表盘索引与 NVS 兼容性。
- 每次锁屏表盘从隐藏状态重新显示时随机选择一个 Grok Bot 风格表情；秒级刷新只更新时间，不重复随机表情。展示当前时间、日期、电量，沿用上游的电量语义、低电量提示、AOD 变暗和熄屏刷新策略。
- 提供 233×233 原生缩略预览，使表盘可由现有设置预览流程检查。
- 解锁继续采用上游实体按键行为，不新增易误触的屏幕滑动解锁。

## Codex 应用

- 在原生启动器增加一个 Codex 入口及匹配黑白红单色图标；应用由 soRound OS 的 `app_t` 生命周期创建/暂停/退出。
- 保留已有 Codex bridge 的用途与数据：用量、Radar、在线/同步状态、活动任务，以及 Codex 内的 VibeBuddy 状态页。无缓存、离线、过期和错误状态必须明确区分，不能用手动滑动条伪造或修改用量。
- 重画页面，使其使用原生标题区、文本字号、绘图工具和圆屏安全边距。页面内容建议为：
  1. **Usage**：显示 5 小时与 7 天额度、重置时间及更新时间；数值来自 bridge，页面只读。
  2. **Radar**：用量化、易扫读的紧凑列表显示模型/评分与更新时间；过期时保留数据并明确标 stale。
  3. **Activity**：显示在线状态、Codex 当前状态、活动任务数及同步时间。
  4. **VibeBuddy**：保留状态角色图像和状态/任务摘要，布局与颜色服从系统页面，避免它变成独立桌面宠物。
- 横向滑动在四个 Codex 子页间切换；返回按 soRound OS 原生返回约定执行。请求失败时保留最后一次有效快照并明确标注离线/过期。
- 复用现有 Mac bridge 与本地会话推断逻辑，不把 Codex 会话正文或凭据传到设备。

## 项目与数据迁移

- 将上游完整固件作为项目结构与功能基线，不删减其现有应用，包括声音胶囊录音。
- 按此前确认清空旧录音，采用上游双 8 MiB OTA 槽及声音胶囊分区布局。刷写分区表属于完整迁移；完成后确认录音分区可读写。
- 重命名固件工程目录为 `Jarvis_OS/`，更新根 README、固件 README、脚本路径、工程名称和文档链接。
- 第三方来源、许可文本和本项目改动边界必须在可复用上游代码前核清并记录。

## 验收

- 主机回归及 ESP-IDF 构建通过；原生 466×466 渲染检查主页、Codex 四页、表情表盘预览、锁屏及 AOD/熄屏状态，不截断、不重叠。
- 真机验证启动器原有应用与设置入口仍可打开；包括声音胶囊录音、回放和删除。
- 真机验证 Codex 联机、离线、过期缓存、各页滑动与返回；用量只能由 bridge 数据驱动。
- 真机验证锁屏每次重新显示表情不同（允许随机重复）、时间日期电量正确、BOOT 解锁与原生省电行为正常。
- 安装新分区表前提醒：设备已有录音按用户授权可清空；不得将分区迁移包装成普通 OTA。
