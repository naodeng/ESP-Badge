# Jarvis_OS Codex 原生 UI 适配

## 目标

将现有 Codex bridge、用量、Radar、Activity 和 VibeBuddy 接入 soRound OS 原生应用生命周期与界面语言。页面不沿用旧版紫青卡片样式；用量只能由 bridge 数据驱动。

## 视觉与导航

- 使用 soRound OS 的原生标题/返回区、黑色画布、暖白主文字、灰色次级文字和红色强调。
- Codex 是启动器中的第 27 个应用。页面复用原生 `app_t` enter/tick/visibility/exit 生命周期；四页横向滑动，系统返回退出 Codex。
- 页面区域适配 466×466 圆屏和原生应用内容区。正文使用现有字体与绘图工具；不要加入自定义渐变背景、悬浮卡片、重复标题或贴边内容。
- VibeBuddy 继续作为 Codex 内的一个状态页；保留原始素材署名，不增加独立桌面角色入口。

## 四个页面

1. **Usage**：展示 5 小时/7 天用量、重置时间、今日 token/cost、套餐与同步状态。用量环是只读呈现，触摸和拖动不会改写数值；缺失窗口显示 `--`。
2. **Radar**：显示最多 16 条模型、epoch 与 IQ 数据，并显示更新时间和过期状态。圆屏范围内不得被截断；无数据、离线缓存和 stale 要有区别。
3. **Activity**：显示 bridge 在线状态、Codex 状态、活动任务数、套餐、设备电量和同步时间。
4. **VibeBuddy**：显示现有状态插画、状态名与活动任务数；离线时显示缓存状态，视觉强调色服从全局黑白红层级。

## 数据与生命周期

- 保留 `/codex.json` 数据结构与当前 Mac bridge；复用 UDP `AGENTBADGE/1` 自动发现，不依赖固定 Mac IP。
- 离线、无缓存、缓存过期和解析错误单独表示。失败请求不清除上次有效快照。
- Codex 页面可见时每 10 秒刷新；应用隐藏、锁屏或退出时暂停请求；不在启动器卡片后台额外轮询。
- fetch 在后台任务执行，LVGL 更新只在原生 UI tick/锁保护下应用。
- 禁止手动调节数据的 slider/可拖弧交互。

## 验收

- 主机测试覆盖有效/缺字段/无效 JSON、16 条 Radar 上限、`p5: null`、缓存过期与失败保留快照。
- UI 测试确认两条 quota arc 不可点击/拖动、四页可切换、返回可退出、Codex 隐藏后停止轮询。
- 原生截图确认 466×466 里 Radar 最后一项可见，长字符串有省略处理，空/离线/过期状态互不混淆。
- 真机验证设备自动发现 Mac bridge、Usage/Radar/Activity/VibeBuddy，断网缓存与恢复。
